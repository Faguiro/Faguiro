## 🌟 Projetos em Destaque

🎨 Alguns dos meus projetos mais criativos e inovadores:

1. [Cube_3D](https://github.com/Faguiro/Cube_3D): Uma representação gráfica simples de um cubo 3D que pode ser girado interativamente usando controles deslizantes. Demonstra os princípios fundamentais de desenho 3D e rotação em um ambiente web. [Demo](https://rotate-cube-3d.netlify.app/)

2. [Python-E-commerce](https://github.com/Faguiro/Python-E-commerce): Loja virtual construída com Django, incluindo funcionalidades como carrinho de compras, página de pagamento com Stripe e painel administrativo.

3. [ollama_tkinter](https://github.com/Faguiro/ollama_tkinter): Aplicação de interface gráfica construída com Tkinter que permite a interação com um modelo de linguagem (LLM), incluindo funcionalidades como visualização de animação durante o processamento e salvamento de respostas.

4. [Fala](https://github.com/Faguiro/Fala): Projeto de reconhecimento de fala utilizando as bibliotecas `speech_recognition` e `gTTS`, permitindo a conversão de fala em texto e vice-versa.

5. [perfil-page](https://github.com/Faguiro/perfil-page): Página de perfil pessoal e currículo online. [Acesse aqui](https://fabiano-rocha.w3spaces.com/)
